# 内容工作台 V2 交互原型

这是独立设计原型，未接入 Flask 路由、生产数据库、生成模型、微信、CMS 或飞书。

启动：

```sh
python3 -m http.server 18766 --bind 127.0.0.1 --directory docs/prototypes/editorial-workbench
```

访问 http://127.0.0.1:18766/ 。原型的文字和裁剪图仅保存在当前浏览器 localStorage；模拟发布记录只保留在当前页面会话。

可操作：草稿列表、正文基础格式、标题/摘要/图注、PDF 原页框选及数值裁框、恢复示例、公众号/Blog 排版示意、模拟多渠道部分失败和单语言重试。上传只读取文件名，使用预置示例，不解析新 PDF。

正式需求和后台契约见 `../../editorial-workbench-v2-design.md`。正式编辑器应使用结构化编辑组件，支持任意页、任意图及独立封面编辑；此单图示例不能直接替代生产编辑器。

资产来自本任务已检查的免疫文章 7-1 原 PDF 第 2 页与 Figure 1；未经生成式修改。示例正文仅说明交互，不作为医学内容或待发布文章。
